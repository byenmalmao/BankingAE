#                                                              Proyecto  bancario con Flask, FideBank 
Applicacion bancaria(banking app) web usando Flask.
🎯 Descripción del Proyecto
Fidebank es una plataforma web moderna diseñada para ofrecer servicios financieros inteligentes. Está pensada para administrar cuentas fiduciarias, préstamos, pagos y gestión de usuarios con una experiencia de usuario fluida y segura.

🚀 Funcionalidades Principales
🔐 Autenticación y perfiles
Registro de usuarios con gestión de sesiones seguras mediante JWT.

💼 Gestión de cuentas fiduciarias
Creación, edición y seguimiento de cuentas asociadas a usuarios.

📤 Préstamos y pagos
Solicitud y seguimiento del estado de préstamos, además de procesamiento de pagos integrados.

📄 Historial de transacciones
Registro completo y filtrable de movimientos financieros por usuario.

🧭 Onboarding personalizado
Proceso guiado para la configuración de perfil y aceptación de términos.

🔔 Notificaciones en tiempo real
Alertas de eventos importantes como aprobación de préstamos o cambios de estado.
